AutoQuiz 智能答题助手

DeepSeek API 配置

在 platform.deepseek.com 申请，仅保存在浏览器本地（chrome.storage.sync）。

答题策略

越小越稳，越大越快。超时报错时请调小。
模拟人工点击节奏，过快可能触发学习通风控。
LLM 返回多空答案时按该分隔符拆分逐空填入，默认英文逗号。
关闭后仅返回答案，不自动点选/写入。

兜底题库

LLM 无法作答（返回空）时自动调用下方接口查题，参考 OCS AnswererWrapper 模式。
支持 ${title} / ${options} / ${type} 占位符，值自动 URL 编码。
返回一个函数，接收响应体（已尝试 JSON.parse），返回 [question, answer] 或 { answer }；默认取 data.answer / data.answers。

答案缓存

同一套卷子（题目内容 hash 作为 key）重复作答直接复用上次答案，跳过 API 调用；存 chrome.storage.local。

共享题库（云端多用户）

答题前先查共享题库，命中则直接使用答案（省 LLM token）；答题后自动上传答案，回顾页回馈官方正确答案（最高权重）。
自托管服务端地址，需先运行 autoquiz-shared-bank-server/server.js（详见 README-server.md）。
与服务端 config.json / 环境变量 SHARED_TOKEN 保持一致。
共享题库中非官方来源的答案需要达到该票数才会被采用，防止单次错误答案污染；官方答案不受此限制。
每次答题后把题目 + AI 答案上传到共享题库（失败自动进入重试队列）。
在平台答案回馈/回顾页自动解析官方正确答案并上传（最高权重，幂等去重）。
